# mapai — локальная учебная копия лендинга heymirai.ai

Статический слепок страницы https://heymirai.ai/ (Next.js, экспортирован в «плоские» файлы)
с заменой бренда Mirai → mapai. Все ассеты (CSS, JS, шрифты, картинки, видео) лежат локально.

## Запуск

```bash
cd ~/mapai
python3 -m http.server 8734
# открыть http://localhost:8734/
```

Нужен именно HTTP-сервер (не открытие index.html через file://) — страница подгружает
JS-чанки и видео fetch'ем.

## Структура

- `index.html` — страница целиком (HTML + встроенные данные Next.js)
- `assets/deploy-public/<sha>/_next/...` — JS/CSS-чанки и шрифты
- `assets/deploy-public/<sha>/public/...` — картинки и видео (~64 МБ)
- `mapai-logo-with-text-black.svg` — логотип-вордмарк (перерисован текстом под «mapai»)

## Что изменено относительно оригинала

- Бренд: Mirai → Mapai, heymirai.ai → mapai.local, founders@heymirai.ai → founders@mapai.local
- Все URL CDN assets.heymirai.ai переписаны на локальные пути
- Логотип: оригинал — векторные кривые «mirai», заменён на текст «mapai» (жирный геометрический шрифт)
- Вырезан пиксель Facebook (трекер)

## Известные ограничения

- Внутренние страницы (/faq, /privacy, /terms, /login, /book-a-demo) не скачаны — ссылки ведут
  на 404 локально. Это отдельные роуты; можно дозеркалить при необходимости.
- Интерактивные демо (карты Mapbox, бэкенд Supabase) **отключены**: публичные ключи оригинального
  сайта удалены из конфига перед публикацией (заменены на YOUR_*_KEY плейсхолдеры в index.html).
  Для локального запуска вёрстка и видео работают без них.
- Вордмарк набран системным жирным шрифтом — при желании можно подключить Poppins через
  @font-face внутри SVG (исходные woff2 лежат в assets/.../_next/static/media/).
