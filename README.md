# nook — локальная учебная копия лендинга (вдохновлён heymirai.ai)

Статический слепок лендинга (Next.js, экспортирован в «плоские» файлы), ребрендирован в **nook**.
Все ассеты (CSS, JS, шрифты, картинки, видео) лежат локально.

## Запуск

```bash
cd ~/mapai
python3 -m http.server 8734
# открыть http://localhost:8734/
```

Нужен именно HTTP-сервер (не file://) — страница подгружает JS-чанки и видео fetch'ем.

Деплой на GitHub Pages: корень репозитория, ветка main (файл `.nojekyll` уже на месте).
Относительные пути рассчитаны на подпуть вида `/<repo-name>/`.

## Структура

- `index.html` — страница целиком (HTML + встроенные данные Next.js)
- `assets/deploy-public/<sha>/_next/...` — JS/CSS-чанки и шрифты
- `assets/deploy-public/<sha>/public/...` — картинки и видео
- `nook/story-mode/...` — сгенерированные иконки для интерактивного квиза
  (household: solo/partner/children/pets; интересы: food-drink/outdoors-pets/culture-nights-out)
- `nook-logo-with-text-black.svg` — логотип-вордмарк (текст «nook»)

## Что изменено относительно оригинала

- Бренд: → Nook (заголовки, копирайт, email-заглушки nook.local, логотип)
- Все URL CDN переписаны на локальные пути
- Иконки квиза «What would life here look like for me?» — сгенерированы заново
  (оригинальные подгружались с чужого CDN и не сохранились); вызов next/image
  пропатчен на `unoptimized`, путь относительный — работает на статическом хостинге
- Вырезан пиксель Facebook (трекер)
- Публичные ключи оригинала (Google Maps, Mapbox, Supabase) заменены на плейсхолдеры

## Известные ограничения

- Внутренние страницы (/faq, /privacy, /terms, /login, /book-a-demo) не скачаны — 404 локально.
- Интерактивные демо с картами (Mapbox/Supabase) отключены — нужны свои ключи.
- Один служебный CSS-класс оставлен с исходным именем (`__mirai`) — техническая необходимость:
  гидратация React ломалась при его переименовании.
